SODA

Privacy Policy · last updated 1 August 2026

SODA does not collect, transmit or share any personal data. There is no account, no sign-in, no analytics, no advertising and no third-party SDK of any kind.

What the app stores

One thing, and it never leaves your device: your best runs. Distance, fastest clear time, cells collected and which zones you have finished are written to the app's own local storage so the game can show your records and unlock the next zone.

  • It is stored only on your device.
  • It is never uploaded anywhere.
  • Uninstalling the app deletes it.

Network

The game is fully self-contained. All graphics, music and code are bundled inside the app, and it does not make network requests while you play. It works with no connection at all.

Permissions

The app requests the standard INTERNET permission, which Android requires for the embedded web view that renders the game locally. It is not used to contact any server. The app also requests a screen wake lock so the display does not sleep during a run.

Children

SODA contains no ads, no purchases, no chat and no user-generated content, and collects nothing, so there is nothing to disclose about data from children or anyone else.

Changes

If a future version ever collects anything, this page will be updated before that version is published, and the change will be described here.
